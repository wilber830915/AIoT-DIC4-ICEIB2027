# IEEE Conference LaTeX Template for Overleaf

This project is a starter template using the standard `IEEEtran` conference
document class. It is suitable as a general IEEE-style conference-paper
starting point; it is **not an official ICEIB template**.

## Import into Overleaf

1. Download `ICEIB_IEEE_Overleaf_Template.zip`.
2. Open https://www.overleaf.com/.
3. Select **New Project → Upload Project**.
4. Upload the ZIP file.
5. Open `main.tex` and compile with **pdfLaTeX**.

## Files

- `main.tex`: Main paper source.
- `references.bib`: BibTeX references.

## Before submission

- Replace the sample title, author names, affiliations, emails, abstract,
  keywords, and all section placeholders.
- Replace the sample bibliography entry with real references.
- Remove unused example content and comments.
- Check the target conference's author instructions for page limits,
  copyright notice, PDF eXpress requirements, anonymity, and any required
  template modifications.
- Do not assume that IEEE formatting is accepted by ICEIB merely because
  it is an IEEE-style layout. Follow the conference's current author kit.

## Adding figures

Upload image files to the project (optionally in a `figures/` folder), then
uncomment and edit the figure example in `main.tex`.
